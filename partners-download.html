⚙️ Installation Instructions

1. Download the binary for your platform above.

2. Make executable (macOS/Linux):

chmod +x mcp-arm-debug-*

3. Configure Claude Code — Edit ~/.config/claude-code/mcp.json:

{
  "mcpServers": {
    "arm-debug": {
      "command": "/path/to/mcp-arm-debug-linux-x64",
      "args": [],
      "env": {
        "OPENOCD_PATH": "/usr/bin/openocd"
      }
    }
  }
}
