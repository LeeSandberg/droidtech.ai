⚙️ Programming Instructions

Target Hardware: Nuvoton M483 MCP (ARM Cortex-M4F)

Using Nu-Link Programmer:

  1. Connect Nu-Link debugger to target board
  2. Use Nuvoton ICP Tool to flash frontpanel_app.hex
  3. Verify programming with device ID check

Using OpenOCD:

openocd -f interface/nulink.cfg -f target/nuvoton_m48x.cfg \
  -c "init; reset halt; program frontpanel_app.hex verify; reset run; shutdown"

Running in QEMU:

qemu-system-arm -M nuvoton-m480 -kernel frontpanel_app.elf -nographic

With GDB Debugging:

qemu-system-arm -M nuvoton-m480 -kernel frontpanel_app.elf -s -S
# In another terminal:
arm-none-eabi-gdb frontpanel_app.elf
(gdb) target remote :1234
(gdb) continue

Inject Test Data:

(gdb) call g_measurement_hal.inject_voltage(37000)    # 37.0V
(gdb) call g_measurement_hal.inject_current(-5000)    # -5A discharge
(gdb) call g_measurement_hal.inject_soc(75)           # 75% SoC

Verify Download Integrity:

# Download SHA256SUMS.txt and verify:
sha256sum -c SHA256SUMS.txt

⚠️ Important Notes

  • Ensure bootloader is flashed before application firmware
  • Application starts at address 0x8200 (after bootloader)
  • Total flash usage must not exceed 220KB limit
  • Always verify checksums before flashing
  • Backup existing firmware before updating
