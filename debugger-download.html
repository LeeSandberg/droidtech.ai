Getting Started with Claude Code

1

Download Binary

Choose your platform above and download the standalone binary. No installation required.

2

Make Executable

On macOS/Linux, run: chmod +x mcp-arm-debug-*

3

Configure Claude Code

Add the server to your Claude Code settings file pointing to the binary path.

4

Start Debugging

Launch Claude Code and use AI-powered commands to debug your ARM Cortex-M firmware.

⚙️ Claude Code Configuration

Add the Embedded AI Debugger to your Claude Code configuration file:

Linux/macOS: Edit ~/.config/claude-code/mcp.json

{
  "mcpServers": {
    "arm-debug": {
      "command": "/path/to/mcp-arm-debug-linux-x64",
      "args": [],
      "env": {
        "OPENOCD_PATH": "/usr/bin/openocd"
      }
    }
  }
}

Windows: Edit %APPDATA%\claude-code\mcp.json

{
  "mcpServers": {
    "arm-debug": {
      "command": "C:\\\\Tools\\\\mcp-arm-debug-win-x64.exe",
      "args": [],
      "env": {
        "OPENOCD_PATH": "C:\\\\OpenOCD\\\\bin\\\\openocd.exe"
      }
    }
  }
}

Supported debuggers: J-Link, ST-Link, CMSIS-DAP, Nu-Link, Black Magic Probe
